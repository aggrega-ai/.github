# Security policy

## Reporting a vulnerability

Open the Security tab of the affected repository and choose **Report a vulnerability**. This opens a private
advisory that only the maintainers can see.

Do not open a public issue for a vulnerability.

## What a report should include

- The affected version. For the CLI, paste the output of `aggrega version`.
- The steps or input that show the problem.
- What you expected to happen instead.

## Supported versions

The latest release is the supported one. A fix ships in a new release; the CLI's releases are at
https://github.com/aggrega-ai/aggrega-cli/releases.

## What happens next

The report is answered and handled through the advisory it opened. When a fix ships, the advisory is published.
